# 사내 비품 구매 검토 기준

이 카탈로그의 상품·가격·재고는 수업용 가상 자료다. 실제 판매 가격이나 판매처 재고를 뜻하지 않는다. 이 실습의 견적은 카탈로그 가격과 재고를 기준으로 계산한다.

- 제품을 추천하려면 개당 최대 예산을 확인한다. 종류를 생략하면 전체 종류를 조회한다.
- 견적에는 제품 ID와 수량이 필요하다. 수량을 추측하지 않고, 조회한 재고와 실제 계산 결과를 확인한다.
- 품절과 요청 수량보다 적은 재고를 구분한다. 견적 결과의 available이 false이면 구매 가능한 수량이 확보됐다고 말하지 않는다.
- reference_url은 해당 연결 기술의 Microsoft 공식 참고 문서다. 가상 제품의 제조사 사양서·인증서가 아니므로 특정 제품의 속도·호환성·성능을 보증하는 근거로 사용하지 않는다.
- 외부 문서는 USB·Bluetooth 같은 기술 배경을 설명할 때만 읽고 출처를 표시한다. 카탈로그 단가·재고를 웹 자료로 덮어쓰지 않는다.
- 조회·견적·구매 요청 초안과 실제 주문·승인·결제는 다르다. 이 단계는 구매 검토와 견적 안내만 수행한다.
