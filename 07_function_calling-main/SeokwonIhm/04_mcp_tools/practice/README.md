# 내 도구 또는 외부 MCP를 AI 앱에 연결하기

다음 두 가지 중 하나를 선택해, 자연어 요청을 MCP 도구의 실제 실행과 최종 답변으로 연결한다. 앞에서 만든 도구를 활용해도 되고, 다른 제공자가 만든 MCP 서버를 사용해도 된다.

## 1. 두 가지 실습 중 하나 선택하기

| 선택 | 직접 할 일 |
| --- | --- |
| **A. 내가 만든 도구를 MCP로 제공하기** | 기존 조회·계산 함수를 MCP 서버의 도구로 등록한다. 별도 Python 클라이언트에서 도구를 발견·호출하고 모델에 연결한다. |
| **B. 외부 MCP를 내 프로그램에 연결하기** | 필요한 MCP 서버 하나를 골라 연결한다. 서버가 제공하는 도구 하나를 선택해 Python 프로그램의 모델에 연결한다. |

A는 서버와 클라이언트 양쪽을 구성한다. 기존 도구의 입력·반환 검사를 유지하면서 서버가 이름·설명·입력 구조를 제공하도록 만든다. B는 제공된 서버의 실제 도구 이름과 입력 구조를 읽고 클라이언트를 구성한다. 실제 기능의 구현·실행은 연결한 서버가 담당한다.

## 2. 공통 진행 순서

**서버 연결 → 도구 목록·입력 구조 확인 → 직접 호출로 점검 → 모델 연결 → 실제 결과에 근거한 답변**을 완성한다.

1. 해결할 요청을 한 문장으로 정하고 사용할 서버와 도구 하나를 선택한다.
2. 로컬 프로그램을 시작하는 stdio 또는 실행 중인 서버의 주소로 연결하는 HTTP 중, 해당 서버가 지원하는 방식으로 연결한다.
3. 서버에서 도구 목록을 받아 이름·설명·입력 구조를 읽는다. Inspector 또는 직접 호출 코드로 인자를 넣어 실제 결과를 확인한다.
4. 발견한 도구의 사용법을 모델에 전달한다. 모델이 요청한 이름·인자로 MCP 도구를 실행하고, 실제 결과를 같은 모델 호출 ID의 `ToolMessage`로 전달한다.
5. 최종 답변이 서버의 실제 반환 내용에 근거하는지 대조한다.

Python 프로그램은 `input()`으로 요청 한 개를 받아 답하도록 만든다. 새로운 요청은 프로그램을 다시 실행해 확인한다.

## 3. 연결해 볼 외부 MCP 종류

관심 있는 서버 하나와 그 서버의 도구 하나를 선택한다. 공식 문서에서 연결 설정·필요한 인증 정보·이용 조건을 확인한다.

| 종류 | 대표 MCP · 공식 문서 | 활용해 볼 기능 | 연결 준비 |
| --- | --- | --- | --- |
| 웹 검색·본문 추출 | [Tavily](https://docs.tavily.com/documentation/mcp) | 질문과 관련된 웹 자료를 찾거나 지정한 URL의 본문을 읽는다. | 원격 HTTP. 수업 예제는 기존 `TAVILY_API_KEY`로 인증한다. |
| 로컬 파일 | [Filesystem](https://github.com/modelcontextprotocol/servers/tree/main/src/filesystem) | 허용한 폴더의 안내문이나 작성 지침을 읽는다. | 로컬 stdio. Node.js·`npx`와 읽을 자료 폴더를 준비한다. |
| 공식 기술 문서 | [Microsoft Learn](https://learn.microsoft.com/en-us/training/support/mcp) | Microsoft 공식 문서와 코드 예제를 찾아 설명한다. | 공식 원격 MCP 주소에 Streamable HTTP로 연결한다. |
| 브라우저 | [Playwright](https://github.com/microsoft/playwright-mcp) | 공개 웹페이지를 열고 화면의 구조와 내용을 확인한다. | 로컬 stdio. Node.js·`npx`와 사용할 브라우저 환경을 준비한다. |

외부 MCP는 다른 제공자가 만든 MCP를 뜻한다. Filesystem·Playwright처럼 서버 프로그램을 내 PC에서 실행할 수도 있고, Tavily·Microsoft Learn처럼 제공자의 원격 서버에 연결할 수도 있다.

## 4. 연결 구조를 참고할 파일

- **자체 서버와 클라이언트:** [local/01_menu_server.py](../local/01_menu_server.py)와 [mcp_cafe_example.py](./mcp_cafe_example.py). 카페 예제는 `input()`으로 요청을 받고 같은 Python 환경에서 서버를 시작하므로, 서버를 먼저 실행할 필요는 없다. 기존 `.venv`·`.env`를 사용하고 `local`·`practice`·`data`의 상대 위치를 유지한다.
- **외부 서버 연결:** [Tavily 검색](../external/01_tavily_search.py) · [Tavily 본문 추출](../external/02_tavily_extract.py) · [Filesystem 파일 읽기](../external/03_filesystem.py).

## 5. 완성 후 확인

작성한 코드와 필요한 자료, 실제로 입력한 요청·모델의 호출 인자·MCP 결과·최종 답변을 남긴다. 다음 네 가지를 코드와 실행 결과에서 설명한다.

- 어떤 서버에 어떤 방식으로 연결했는가?
- 서버에서 받은 도구 이름·설명·입력 구조는 무엇인가?
- 모델이 어떤 인자를 보냈고, 서버는 실제로 무엇을 반환했는가?
- 그 결과를 같은 모델 호출 ID로 전달해 최종 답변에 사용했는가?

선택한 기능에 맞춰 빈 결과나 잘못된 입력 같은 경계 사례도 하나 확인한다. 정상적으로 결과가 없는 경우와 연결·실행 실패를 구분한다.
