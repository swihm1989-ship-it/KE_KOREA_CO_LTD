사용자가 주문서나 참고 자료를 입력하면, 앱은 이미지와 PDF의 내용을 구조화된 초안으로 추출합니다. 특히 PDF는 페이지별 텍스트를 읽고, 스캔처럼 텍스트가 거의 없는 페이지는 이미지로 변환해 인식합니다. 추출 결과의 제품명은 SKU와 용량 등 카탈로그 정보에 대조합니다. OCR 오타가 있더라도 유사한 후보를 찾을 수 있지만, 점수가 낮거나 제품 조건이 충돌하면 가격을 임의로 git status --short
git log -1 --oneline
git push origin main확정하지 않습니다. 확인이 필요한 항목은 사용자에게 다시 보여주고, 직접 수정한 제품명도 견적서에 반영합니다.

가격과 금액 계산은 생성형 모델에 맡기지 않습니다. Supabase의 거래처·제품 가격 정보를 문서 역할과 통화에 맞춰 조회하고, 수량·할인·증정·포장 합계는 결정론적 검증으로 계산합니다. 필수 정보가 빠졌거나 원본과 계산이 다르면 검토와 승인이 끝날 때까지 파일 생성을 제한합니다. 승인 후 PDF와 Excel 초안을 내려받을 수 있습니다.

개발 과정에서는 상품 코드가 이름에 붙어 가격 조회가 실패하는 문제, 일부 미일치 행 때문에 맞는 상품까지 가격이 누락되는 문제, 메뉴 이동 중 입력이 사라지는 문제, 0 수량을 미입력으로 오해하는 문제를 각각 재현해 수정하고 회귀 테스트를 추가했습니다. PDF 처리도 텍스트 PDF와 스캔 PDF 경로를 보강했습니다. 다만 특정 실패 PDF의 원인을 확정하거나 모든 추출을 보장하는 것은 아닙니다.
